# 世界书更新

在「彩蛋服务 → 检查更新」中与正则、常驻脚本一起检查。世界书清单及条目来自最新已验证正式固定版，通过签名正则中的源提交和清单摘要核对，不受当前固定版旧资源目录限制。仅处理当前绑定范围内能按版本标记或受管理旧版签名识别的条目。

玩家选择「更新可用项目」后：

1. 下载并验证条目，在写入前重新核对聊天、角色及目标条目；
2. 旧条目改名为「备份·v旧版本号·原名」并关闭；
3. 写入并启用新条目，成功后清理更早备份；失败时恢复旧条目并保留原有备份。

世界书先于可能重绘界面的正则和常驻脚本执行。部分失败会保留已完成项目，并提示重新检查。保留的非固定兼容版自动提示同样进入此唯一更新页；固定版正常刷新仍不检查最新版本。

## 发布新版

1. 修改 `读者核心本体.txt`，并把**第一行**版本标记里的版本号调高，例如：

   ```
   <%_ /* DREAM_WORLDBOOK reader-core v2026.10.08 */ _%>
   ```

   这一行是 EJS 注释，渲染后为空，正文模型读不到。
2. （可选）在 `notes.txt` 写更新说明，会显示在弹窗里。
3. 提交即可。GitHub Actions 会自动重算 `manifest.json`（版本、字节数、SHA-256）。

`entries.json` 记录条目名、旧版识别规则（没有版本标记的旧条目按名字和内容识别）和插入设置（常驻、@D 深度 1、顺序 1100），一般不用改。
