# 世界书更新

读者对话渲染会在打开时（每 6 小时最多一次）比对玩家当前角色绑定的世界书和这里的版本；发现旧版时弹窗提示，玩家确认后：

1. 同一世界书里该条目更早的备份被删除（只保留最近一次备份）；
2. 旧条目改名为「备份·v旧版本号·原名」并**关闭**；
3. 写入并启用新条目。

玩家也可以在「彩蛋服务 → 世界书更新」手动检查。

## 发布新版

1. 修改 `读者核心本体.txt`，并把**第一行**版本标记里的版本号调高，例如：

   ```
   <%_ /* DREAM_WORLDBOOK reader-core v2026.10.08 */ _%>
   ```

   这一行是 EJS 注释，渲染后为空，正文模型读不到。
2. （可选）在 `notes.txt` 写更新说明，会显示在弹窗里。
3. 提交即可。GitHub Actions 会自动重算 `manifest.json`（版本、字节数、SHA-256）。

`entries.json` 记录条目名、旧版识别规则（没有版本标记的旧条目按名字和内容识别）和插入设置（常驻、@D 深度 1、顺序 1100），一般不用改。
