# 相册（CG 鉴赏）

在酒馆里打开「彩蛋服务 / 彩蛋设置 → 相册 · CG鉴赏」即可浏览这里的图片。

更新方法（任选其一，均可直接在 GitHub 网页上操作）：

1. **上传图片**：把 png / jpg / jpeg / webp / gif / avif / bmp 图片放进本文件夹（`gallery/`）。文件名即标题，按文件名自然排序（建议 `01-标题.png`、`02-标题.png`）。
2. **外链图片**：编辑 `links.txt`，每行写一张图片的外链，可写成 `标题 | https://...`。

删除图片或删掉 `links.txt` 中的对应行即可下架。

外链固定在完整 Commit SHA：推送后 GitHub Actions 会重建 `index.json`、把内容计数加一并固定新版本；玩家打开读者界面时会收到「内容更新」提醒，换成新版本号（或一键替换）并刷新后即可看到新的 CG。

`index.json` 由 GitHub Actions 自动生成（相册按它显示），无需手动编辑。
