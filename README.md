# reader

神秘咖啡女（九十九夜梦 · 读者）外链仓库。

读者正则统一为轻量信件「读者对话渲染-脚本版」。命定之诗由现有自动正则加载并托管读者，不创建额外的脚本库条目；新楼层、编辑和重新生成不会打断播放。正常启动使用卡内版本，或上次手动确认并保存在本地的版本，不检查新版、不拉更新清单、不重复下载运行时。只有在读者「检查更新」中确认更新时才下载、校验并保存新版本，下次启动读者生效，当前音乐保持不变。源码、构建和宿主接口见 [常驻运行时](docs/runtime.md#运行方式)。

常驻入口复用原悬浮信封；彩蛋服务新增「隐藏常驻悬浮窗」，默认关闭。唱片机第六专辑「书海」收录 124 首配乐，播放时才加载当前一首，无需另传外链。

主卡4.4发布前，旧版命定之诗（自动正则默认资源 `1.2.2`）临时恢复脚本更新：在「检查更新 → 更新可用项目」确认后，新版轻量正则会继续安装同一版脚本，接通原先显示「脚本不可更新」的旧入口；立即重载时播放会中断，重启联网恢复已确认版本，不安装额外脚本。需要有一封读者来信显示以运行更新后的正则。新版托管入口仍按上文使用本地缓存。适用范围和撤销方法见 [主卡4.3临时兼容](docs/runtime.md#主卡43临时兼容)。

原鲨鱼盘失效的六首唱片已改由本仓库 [`audio/`](audio/) 托管，FLAC 转为 192 kbps MP3；保留原曲名，并自动替换已保存歌单中的对应旧链接。与书海专辑一样，播放时才下载当前曲目，校验后播放。

## 不用命定之诗时的安装

从最新的 `v<数字版本>` Release 下载 `reader-fixed.regex.json` 导入正则。它第一次显示时会把「读者常驻脚本」装进同一范围（角色或全局）的脚本库，确认保存和启动后自动换成轻量信件；之后在「彩蛋服务台 → 检查更新」更新。需要启用「酒馆助手（JS-Slash-Runner）」和对应范围的脚本开关。

这是不使用命定之诗自动正则时的独立安装方式；命定之诗玩家无需单独导入读者脚本。

下面是旧入口的说明，只用于理解已有安装：外链版和固定版都会自动迁移，不要再新装。

## 旧入口

固定版发布后，可从对应 `v<数字版本>` 的不可变 Release 下载 `reader-fixed.regex.json`。固定版刷新不升级；在「彩蛋服务台 → 检查更新」中对比读者和书海版本，点击「更新可用项目」后才替换，也可只改正则中的 `VERSION` 数字。固定版与自动更新版只启用一份。[固定版使用和发布说明](docs/fixed-releases.md)。

旧固定版升级到脚本版时，会自动安装酒馆助手脚本库中的「读者常驻脚本」，确认保存和启动后再切换轻量正则。若对应的角色或全局脚本总开关关闭，开启后重新检查即可；安装失败时保留完整版。

世界书中的「读者核心本体」保持启用（发言限制、称呼设置等功能需要配套的核心版本）。

## 黑幕人格（2026.10.26.5）

“黑幕”默认使用哀怜的少女；符合当前关系列表条件时，本轮切为黑之作家，执行后根据下一轮 MVU 自动判断是否恢复。事件进度达到聊天固定阈值后，黑之作家常驻、好感阈值从70降为30。其他人格和IF不触发。

读者正则显示时自动、静默地把完整人格资料保存进当前聊天，之后世界书从聊天变量读取，不在EJS里联网，不需额外操作。升级时使用同版世界书核心，已有外链正则会随仓库更新获取新脚本。详细规则见 [CONTEXT.md](CONTEXT.md)。

## 外链如何工作

- 外链版正则只包含一个加载器：读取 `release-manifest.json`，再按清单下载 `dist/` 中的样式、正文模板和脚本。
- 依次尝试 GitHub Pages（`adirm007.github.io/reader`）、`raw.githubusercontent.com` 与 jsDelivr；任一可用即可。
- 安全上下文（HTTPS 或 localhost）下会校验 SHA-256 并缓存到浏览器，离线时使用上次成功加载的版本；局域网 HTTP 访问时仅校验字节数。
- 全部失败时会显示信件原文和「再试一次」按钮。

## 作者更新流程

```bash
python tools/build_release.py "<完整版读者对话渲染.json>" 2026.10.07.6
git add -A && git commit -m "Release reader 2026.10.07.6" && git push
```

`dist/` 中的文件以内容哈希命名，旧文件可以保留，避免 CDN 缓存期间清单与文件不一致。

## 命运抽卡

大厅里的「命运抽卡」打开抽卡面板（配色跟随当前大厅主题）：选文学或 ACGN 与主题后换大池，从公开资料库捞起 99 部作品；挑一部让夜梦编纂小池，再单抽或十连（混池：物品、命运与角色混在一起抽，不能指定），抽到的东西按命定之诗品质放进主角背包，保底、抽取点数与记录随聊天保存。

小池合计 54～99 张：物品与命运各有多少、品质怎么分配，都由夜梦按作品决定，不定死；物品里至少 9 件神话。编纂的最后一步读世界书里的「世界观物品生成细则」条目（默认「技能装备道具生成规则」「品质效果限定」「核心数值表」「状态规则」，设置里可改），给装备、武器、消耗品、资产等写出类型、标签与效果，抽进背包就能直接用；技能书页、命运与角色书页由正文模型在使用时生成完整属性。抽卡设置里的「角色池」默认关闭，打开后小池再加上角色（物品 + 命运 + 角色仍是 54～99 张，不强制均分）。角色全部是**唯一**品质，出货率与神话相同，同一部作品里抽到过的角色不会再出现。抽到的角色以书页的形式由主角持有，实力完全等同原作；一旦被选择具现，便在完全保有自身自由意志的情况下自由行动，主角无法强制约束。

| 操作 | 命运点 |
| --- | --- |
| 换大池（撒网捞起 99 部，捞到之后才扣） | 1000 |
| 小池单抽 | 200 |
| 小池十连（至少一张稀有） | 2000 |
| 大保底兑换（用这部作品的 200 点抽取点数） | 0 |
| 回收（每件，按品质） | 普通 8 · 优良 20 · 稀有 100 · 史诗 200 · 传说 2000 · 神话 6000 · 唯一 6000 |

神话与唯一基础各 0.3%，120 抽内必出一张随机神话（小保底，各池共用，平均约 101 抽一张；唯一不算）。界面只显示命定之诗的品质名。在一部作品的小池里每抽攒 1 点抽取点数，攒满 200 点可兑换这部作品小池里指定的一张神话（大保底）；点数只能在这部作品的小池里使用，不跨池互通。回收价是同层级角色缔结命定契约基础价的 1/25，抽了再回收换不回本。源码在 [`gacha/`](gacha/)，说明见 [常驻运行时](docs/runtime.md#命运抽卡)。

## 相册（CG 鉴赏）

在 `gallery/` 中上传图片，或在 `gallery/links.txt` 中逐行写入图片外链，酒馆内「相册 · CG鉴赏」即会同步显示，支持翻页、大图浏览与下载原图。详见 [`gallery/README.md`](gallery/README.md)。

## 额外人格库（DLC）

与相册同一原理：把「人格管理」导出的人格 JSON 放进 `personas/`，酒馆内「彩蛋服务 → 额外人格库」就会列出；玩家选中一位并启用，她会作为自定义人格进入玩家自己的人格库并立即启用。修改文件后玩家端显示「有更新」，删除文件即下架（已启用的副本不受影响）。详见 [`personas/README.md`](personas/README.md)。

## 世界书更新

读者核心条目第一行写有版本标记（EJS 注释，正文模型读不到）。统一在「彩蛋服务 → 检查更新」分别检查正则、常驻脚本和世界书；仅更新过旧项目，部分失败会逐项显示。世界书取自经过发布证明、固定清单和内容 SHA-256 校验的版本，旧条目先改名备份并关闭，成功写入新版后才清除更早的备份；写入失败会恢复旧条目。脚本版始终使用轻量正则，独立脚本最后热替；自动正则托管版保存后下次启动生效，两种方式都保持单实例。详见 [`worldbook/README.md`](worldbook/README.md)。

## 独立API

「彩蛋服务 → 独立API」可保存多套方案（地址、密钥、模型）一键切换，拉取模型列表后可直接下拉选择，也可手动填写模型名；人格创作、缘加强、书架定调、条目模仿、命运抽卡，以及《书海》的技能整备、补给员对话可以分别指定方案。密钥只保存在本浏览器，正文回复仍走酒馆当前插头。
