# 额外人格库（DLC）

在酒馆里打开「彩蛋服务 / 彩蛋服务台 → 额外人格库」即可看到这里的人格。玩家选择一位并点「启用」后，她会作为**自定义人格**复制进玩家自己的人格库并立即启用。

更新方法（都可以直接在 GitHub 网页上操作）：

1. **新增**：在酒馆「人格管理」里导出人格 JSON，把文件放进本文件夹（`personas/`）。文件名随意，建议用人格名，例如 `哀怜的少女.json`。一个文件可以放一位人格，也可以是 `{"personas": [...]}` 形式的多位人格；可在顶层写 `"author": "作者名"`。
2. **修改**：直接替换同名文件。已经启用过的玩家会在列表里看到「有更新」，点「更新并启用」即可覆盖她的副本（保留玩家改过的名字）。
3. **下架**：删除文件即可。已经启用过的玩家，人格库里的副本不受影响。

人格 JSON 必须包含人格管理要求的必填字段（系统名、定义、核心概念等），否则玩家启用时会提示缺少的字段。

`index.json` 是自动生成的备用索引（GitHub 目录接口不可用时使用），无需手动编辑。玩家端会缓存列表约 10 分钟，点「刷新」可立即重新读取。
